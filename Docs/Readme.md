# American Ask4 Logistics Website

A modern responsive logistics website built for **American Ask4 Logistics**.

---

## Features

- Responsive Design
- Modern TailwindCSS UI
- Quote Request Form
- Firebase Firestore Integration
- Offline Form Backup (LocalStorage)
- Scroll Animations
- Mobile Navigation
- Privacy Policy Page
- SEO Optimized
- Open Graph Meta Tags
- Performance Optimized

---

## Tech Stack

- HTML5
- TailwindCSS
- JavaScript (ES6)
- Firebase Firestore
- Firebase Analytics

---

## Pages

- Home
- Privacy Policy
- Terms & Conditions

---

## Main Functionalities

### Quote Form

Customers can request a shipping quote.

Information is stored in Firebase Firestore.

If Firebase becomes unavailable, submissions are automatically saved in LocalStorage.

---

### Responsive Navigation

Fully responsive mobile navigation with animated sidebar.

---

### Animated Statistics

Animated counters for:

- Customers
- States Covered
- Support Availability
